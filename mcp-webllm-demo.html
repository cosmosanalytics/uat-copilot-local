The Server Never Changes

A real MCP-shaped JSON-RPC 2.0 server exposes four supply-chain tools. Swap the model running the client — via real in-browser inference (WebLLM / WebGPU) — and watch the wire protocol, the tool schemas, and the server's fingerprint stay byte-for-byte identical. Only the reasoning changes; the interface is the moat.
