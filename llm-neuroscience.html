Record, lesion and stimulate an open-weights language model, the way we study a brain

Neuroscience for an LLM

Load a small open-weights model into your browser (GPT-2, Pythia, SmolLM2 or Qwen2.5) and open it up the way neuroscientists open up a brain. Record its activity, read out what it is thinking at each layer, probe single neurons, measure its surprise, find induction circuits, lesion parts to see what breaks, and stimulate or steer it. The math runs on your device, on WebGPU when it works.

  1. Recording: Activity of every layer at every token, like an fMRI scan, plus a depth profile of what each layer does.
  2. Logit lens: Read out what the model would predict at each stage of its depth.
  3. Connectivity: Which token each attention head looks at, and a test that finds induction heads.
  4. Contribution: Which heads and layers push the model toward its answer.
  5. Single unit: Record one MLP neuron across texts, like a single-cell recording.
  6. Surprise: Token-by-token surprisal, the model's version of the N400 brain response.
  7. Lesions, stimulation and steering: Knock parts out, patch activity between prompts, or add a direction to the activity and watch the behavior change.

Honest label: this is a small open-weights model (GPT-2, Pythia, SmolLM2 or Qwen2.5) running through code written for this page, because the engines that run chat models in the browser do not expose their insides. The weights download from huggingface.co when you load the model, and nothing you type leaves your device. Matrix math runs on WebGPU only after it passes a self-test against plain code, otherwise it runs on the CPU. The architectures were checked against reference code on small synthetic models, not against the real downloaded weights, so run the Checks tab after loading. Interpretability methods have known limits: a lesion can break a model in ways that have nothing to do with the function you wanted to test, the logit lens is a rough guide, single neurons in GPT-2 are mostly polysemantic, and what you find in one prompt may not hold in another. Sparse autoencoders, which need separately trained weights, are not included. Treat results as hypotheses.
