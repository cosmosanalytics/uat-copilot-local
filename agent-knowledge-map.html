Turn each agent's notes into a knowledge graph, see which areas each agent knows, and watch conversations change the map (a WebLLM chat model, scored against a known world)

Can LLMs map what an agent knows?

Three agents each hold a few notes about a small company. An LLM reads the notes and extracts facts, code builds a knowledge graph for each agent, finds its areas, and an LLM names them. You see which areas each agent knows and how well the map matches a hidden answer key. Then the agents talk: each answers from its own map, the listener's LLM extracts what it heard, and the listener's map changes. A wrong claim can be injected, and three trust policies can be compared on the same conversation.

  1. The world: A small company with four areas (suppliers, quality, finance, logistics) and a hidden answer key of 29 facts.
  2. The maps: An LLM reads each agent's notes into triples, code builds the graph and finds the areas, an LLM names them. A rule-based reader is included as a baseline.
  3. The coverage grid: Which areas each agent knows, scored against the key.
  4. The conversations: Retrieval from the speaker's graph, a spoken message, extraction by the listener, and a merge with a trust policy. New, reinforced, replaced and conflicting facts are drawn.
  5. Policies and your own text: Newest wins, own notes win, or keep both and flag. Replayed on the same messages, with no extra model calls.

Honest label: this is a small, hand-built world with a hidden answer key, so the scores show how an LLM reader behaves here, not how it behaves on your documents. The graph covers what an agent has written down and what it hears, not what its model weights know. The areas are the groups of nodes that are linked together, so they only separate cleanly because the facts here share hub words like supplier, and one wrong link could merge two of them. A small on-device model will miss and invent facts, and the page counts both. The rule-based reader only understands this page's sentence patterns. Nothing leaves your device.
