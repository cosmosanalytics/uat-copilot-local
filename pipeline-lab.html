Pipeline Lab

A small customer-support triage workflow that runs for real in your browser: Python and pandas, SQL on SQLite, a language model on your GPU, and tracked runs you can query.

Cleans the data, runs two prompts and opens the run comparison.

    What is real here: the Python and pandas code, the SQL (SQLite), the model (WebLLM on WebGPU), and the confidence scores taken from the model's own token probabilities. What is imitated: PySpark and MLflow cannot run in a browser, so their code is shown for reference and runs are tracked by a small SQLite tracker with the same method names. The agent trace is a scripted illustration. Check AWS and Databricks documentation before relying on any specific feature.
