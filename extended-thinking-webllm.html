Extended Thinking, Under the Hood

Give a local model an explicit reasoning budget before it has to answer, and watch what changes. Run the same prompt with no thinking budget next to a chosen budget, side by side, using a model running entirely in your browser via WebGPU.

What this actually is: this page does not use Anthropic's real Extended Thinking feature (a distinct model capability, invoked with a thinking: {budget_tokens: ...} parameter on the Claude API, which produces genuine interleaved reasoning). It approximates the same idea — forcing a deliberate reasoning pass, bounded by a token budget, before the final answer — with plain two-stage prompting against a small open-source model in your browser. Useful for building intuition about why a reasoning budget matters; not a substitute for the real API feature.

Problem Idle

Load a model, pick a problem, then run to see the reasoning trace and final answer.
Demo only. Model quality varies a lot at this scale (small models run fully client-side so the demo works with zero backend and zero API cost) — the point isn't that the model gets every problem right, it's seeing how the reasoning trace changes the final answer when it's allowed to work through the problem first versus forced to answer immediately. Runs entirely in your browser via WebLLM / WebGPU — nothing is sent to a server.
