Unit Economics, Under the Hood

Two mechanisms enterprises use to keep LLM costs sane at scale: asymmetric model routing (send easy work to a cheap model, hard work to a capable one) and prompt caching (stop re-paying for the same static context on every call). One is demoed live with two real local models; the other is a calculator using Anthropic's real published cache economics.

1. Asymmetric model routing

Live · real models

A cheap local model triages each task as routine or complex. Routine tasks are answered by the cheap model itself; complex tasks get forwarded to a larger, more capable model. Dollar figures use Anthropic's real published per-tier pricing (as illustrative $/M-token labels — your browser isn't actually being billed) so the routing math is tangible.

2. Prompt caching

Calculator · real published economics

This section needs no model or GPU — it's a calculator, not a live test. WebLLM doesn't expose a controllable cross-request cache the way Anthropic's API does, so rather than fake a live demo, this applies Anthropic's real published cache pricing (first write ≈1.25× base rate, cached reads ≈0.1× base rate — roughly a 90% discount after the first call) to a scenario you control.

Scenario

Tokens of static content repeated on every call — a system prompt, schema docs, retrieved reference material.

All within the 5-minute cache TTL — e.g. a burst of requests in one user session, or one agent looping over sub-tasks.
