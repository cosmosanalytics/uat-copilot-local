SemIf Core Protocol: The Typed Answer Trick Zero-free-text generation

The model receives max_tokens = 1, temperature = 0, logprobs = true, top_logprobs = 5 with system constraint: "Reply with exactly one option letter and nothing else." Probabilities are extracted from logprob logits, renormalized over valid option letters only (P = exp(logit) / Σ exp(logit)), discarding free text hallucinations.

Critical Calibration Invariant:

"Probabilities from raw logits are NOT guaranteed to be calibrated. Check them on your own labeled cases before gating anything." Raw LLM logits are typically overconfident due to pretraining loss dynamics. The Calibration Lab computes Expected Calibration Error (ECE), draws an empirical reliability diagram, and fits temperature scaling \(T\) to align confidence with observed ground truth accuracy.
