1. Education Harness (Grounded Ingestion)

Instead of sending raw prompts into an unconstrained LLM, the Education Harness constrains the LLM with an active Semantic Ontology and retrieves indexed historical precedents from the Context Graph.

2. Calibration Harness (Metacognition)

The foundation LLM generates multiple candidate rollouts. The Calibration Harness monitors conflict entropy across rollouts and calibrates stated probability so that 90% confidence means ~90% empirical accuracy.

3. Gate Harness (Action Dispatch)

The Gate Harness applies the instrumental risk threshold. Even a perfectly calibrated agent requires a threshold tuned to the cost of mistakes. When mistakes happen, weak spots flow directly back to amend the rules in the Education Harness.

Epistemic (steps 1 and 2): Confidence matches the facts.
Instrumental (step 3): The threshold balances both mistakes.
"A well-calibrated agent can still be reckless or timid if the threshold is wrong."
