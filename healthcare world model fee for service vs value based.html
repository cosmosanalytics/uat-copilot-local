Healthcare World Model — Fee-for-Service vs. Value-Based

Two orchestration paths branching from the same care journey, once Utilization Trend Forecast flags a worsening trend. Path A — Fee-for-Service (traditional): approve the planned high-cost service (e.g. a $2,400 MRI), then run the standard claims cycle — Prior Authorization → Clinical Encounter → Medical Coding → Claim Submission → Adjudication → Payment Posting / Denial Management → Patient Billing. Path B — Value-Based Care (capitated): reroute to a cheaper in-home nurse visit instead, skip the claims cycle entirely, stabilize the condition, and bank the avoided cost as Medical Loss Ratio savings. Every tool in both paths is a pure, deterministic function (deductible/coinsurance math, CPT/ICD-10 coding, a least-squares utilization forecast, reroute and savings math) — and at every stage in either path, deciding what to run next is just a pick from a short, fixed menu. That's the same job an LLM tool-calling orchestrator does, so you can drive either path with a plain menu, or with a small (<2B parameter) local instruct model reading plain text — no native tool-calling API, no large model. Run stages manually to study the logic either way. Stage order and definitions are adapted from published revenue-cycle-management and utilization-management literature (see footer for sources) and simplified for illustration — this is not medical, billing, or legal guidance.

Claim adjudication
The contracted "allowed amount" is what the payer recognizes as payable at all; the difference from the billed charge is a contractual write-off the provider absorbs — not paid by the patient. Set this to 0 to force a denial and exercise the appeals path.
Denial management — appeal
Only used if Adjudication results in a denial. Strength ≥ 0.6 overturns the denial on appeal (simplified); below that, the denial is upheld and the claim closes as a provider write-off with no plan or patient payment.
