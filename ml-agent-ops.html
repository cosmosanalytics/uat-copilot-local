An LLM pipeline with a tool-using agent, start to finish

ML Agent Ops

Clean messy support messages, sort them with a model, check the result before release, protect private data, then let an agent act on the confident ones while unsure ones go to a person. One button, no settings.

Honest label: the data cleaning, SQL, pandas, release checks, agent loop, tool permissions, policy rules, approval step and traces are real code running in your browser on made-up data. The sorting step uses pre-recorded demo answers, and the agent follows scripted rules, unless you load a small on-device model, which then does both. The MLflow-style tracking and Databricks-style masking imitate those tools with SQLite and plain code. Nothing here calls AWS.
