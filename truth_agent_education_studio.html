🛡️ GroundTruth Architecture: Dual-Role Ground Truth Pipeline

One human-approved source of truth performs two vital jobs: it is The Book that teaches the agent, and the hidden Answer Key that grades it. Because an inaccurate book can damage a correct model, humans approve the pages first.

Step 1 📘 THE BOOK
Write the Truth

Collect multi-docs, reconcile conflicts, publish authoritative web portal with named page owners & human sign-off.

Step 2 🔑 ANSWER KEY
Map the Live Truth

Spider crawl pages, distill ARIA semantic trees, and build AI Journey DAG roadmaps with dead-end checks.

Step 3 🩺 DIAGNOSE
Test Baseline Agent

Test frozen model unaided against synthetic exam questions. Rank knowledge gaps on radar matrix.

Step 4 🎓 EDUCATE & KEY
Educate & Verify

Apply 5 levers of education (The Book). Run hidden exam key, eliminate hallucinations, trace errors.
