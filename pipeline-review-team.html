Paste agent pipeline code and let a team of reviewers check it, with a code analyzer and an on-device model

A review team for agent pipeline code

Paste the design code of an agent pipeline. A static analyzer draws the pipeline as a graph and finds problems in plain code. Then four reviewer agents, each with its own working memory, look for more, a fresh verifier checks every finding against the code, and a synthesizer ranks the result. Try it on the samples, where the seeded problems are known.

  1. Static analyzer (code): Reads the code, draws the pipeline as a graph and applies rules from the executive brief. No model.
  2. Four reviewers: Structure, incentives, safety and grounding. Each sees the code through its own checklist.
  3. Verifier: Starts fresh. It sees only a finding and the lines it cites, and says whether the code supports it.
  4. Synthesizer: Merges, removes duplicates, ranks by risk and writes a short summary.
  5. You: Paste code or pick a sample, and compare the team with one reviewer on its own.

Honest label: the static analyzer reads the text of the code with simple pattern rules. It does not run or fully parse it, so it can miss problems and flag false ones, and it works best on short, readable pipeline code in Python or JavaScript. The model reviewers are a small on-device model, so they will miss things and some of their findings will be wrong, which is why every one is checked against the code. The samples are made up, with seeded problems. A score on three samples proves very little. Nothing leaves your device.
