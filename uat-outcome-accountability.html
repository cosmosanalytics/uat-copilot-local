iWhat this demonstrates

A companion to UAT Copilot, applying the same accountability framework used elsewhere in this project — but adapted honestly to a vision model. The underlying model here always decodes deterministically (no randomness), so unlike a text model, asking it the same question twice gives the same answer — self-consistency sampling wouldn't produce a real confidence signal. Instead the safety net here is stricter: every AI read of a screen requires a named tester's sign-off before it counts as a test result — nothing is ever auto-passed. The AI also flags its own uncertain language automatically. What closes the loop: after sign-off, if a defect later surfaces on a step that was confirmed, you can mark it "later found incorrect" — so real accuracy (not just process) becomes measurable by tester and by whether the AI hedged.

No model load or screen share needed — loads 6 already-completed steps so you can browse the Step log and Dashboard right away.

Runs fully client-side, same engine as UAT Copilot: a SmolVLM model via Transformers.js on WebGPU, loaded through worker.js (must be deployed alongside this file — it's the same worker UAT Copilot uses). All steps, sign-offs, later outcomes, and the audit log persist in this browser's local storage. Nothing is uploaded anywhere.
