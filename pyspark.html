PySpark API (runs on a pandas-backed shim)

PySpark lab

Write PySpark code and watch what Spark would do: transformations are recorded lazily, actions trigger jobs, and wide operations add shuffles and stages. The results are computed by pandas, because real Spark needs a Java runtime.

Honest label: this is a small PySpark-compatible shim written for this page, not Apache Spark. The API names, lazy evaluation, show() output, explain() shape and the job, stage and task counts are modelled on Spark, but the numbers are simplified. The data results come from pandas and SQLite.
