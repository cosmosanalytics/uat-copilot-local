🛠 Three Diagnostic Tools
🗂️
SAE Feature Probe — "What concept activated?"
Sparse Autoencoders decompose the model's residual stream into thousands of named features. Each feature corresponds to a human-readable concept. At inference time you can read which features fired, with what intensity, and whether they were appropriate for the prompt.
→ Reveals: wrong entity retrieved, missing uncertainty, false confidence
🔥
Attention Monitor — "What did the model look at?"
Attention weight matrices show which tokens each head attends to. A hallucinating model in RAG tasks stops attending to the source document and attends to its own fluent prior tokens — a measurable, detectable pattern before the wrong answer is generated.
→ Reveals: context ignored, pattern-completing instead of fact-retrieving
🎯
Causal Tracing — "Which weight stores the wrong fact?"
Run the model on a corrupted prompt, then restore clean activations one layer/position at a time. The layer where restoration recovers the correct answer is where the fact is encoded. ROME/MEMIT can then rewrite that specific weight — editing 0.003% of parameters.
→ Reveals: exact MLP layer storing wrong factual association

💊 Three Fix Strategies
✂️
Targeted Weight Edit (ROME / MEMIT)
Rewrite the specific MLP weight storing the wrong fact. Permanent. Edits <0.01% of weights. Safe, precise, no retraining.
🧲
Attention Steering Vector
Add a learned vector to the attention keys that pulls focus back to the source context. Applied at inference — no weight change. Temporary, prompt-level.
🚦
Epistemic Probe Gate
A linear probe on layer 24 activations predicts "is this claim grounded?" and injects a hedge token or triggers abstention before output. Real-time safety net.
