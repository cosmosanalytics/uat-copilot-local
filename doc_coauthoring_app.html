# Doc Co-Authoring Runbook (Skill #14)

## Core Stages
1. **Stage 1: Context Gathering**
   - Probe initial goals, audience, and scope.
   - Accept unstructured brain dumps and extract key architectural invariants.
2. **Stage 2: Refinement & Structure**
   - Ask 2–3 targeted clarifying questions.
   - Brainstorm candidate sections and curate an explicit hierarchy.
   - Perform a gap check before drafting.
3. **Stage 3: Section Drafting**
   - Co-author section by section with user verification.
   - Enforce tone consistency and concrete technical details.
4. **Stage 4: Reader Testing**
   - Simulate a skeptical technical reader's perspective.
   - Polish definitions, eliminate acronym ambiguity, and verify export readiness.
