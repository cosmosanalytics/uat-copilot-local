LangChain and Strands, all the way down (a real on-device model)

Agent builder regress

Build an agent. Then build the agent that builds it. Then the builder of that builder. Watch how far down the turtles go, how much of your goal survives each hand-off, and whether the tower ever settles. Just for fun, and surprisingly instructive.

Honest label: LangChain and Strands are Python libraries and do not run in this page. This lab runs a miniature agent loop in JavaScript on a small open model through WebLLM and WebGPU, and shows the real Python pattern for each framework. Every level is another model call, so the tower is capped, and the top level is always written by a human, because infinite regress needs a starting point. Small models make mistakes, so expect the goal to fade, which is the point. Library APIs change, so check each library's documentation.
