Cognitive Scaffold

A small language model runs in your browser. Climb the stairs to wrap it in more of a human mind, one module at a time, and watch how its answers change.

Needs Chrome, Edge or Safari with WebGPU. The model downloads once, then is cached.

WebGPU isn't available in this browser. Open this file in a recent Chrome or Edge on desktop (or Safari 26+), and make sure hardware acceleration is on.

The architecture

Every module is the same LLM, called with a different job. Lit modules are active at this level.

Working memory

Holds 7 items, like the human span of 7±2. The oldest is forgotten when full.
