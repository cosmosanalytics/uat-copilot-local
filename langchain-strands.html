LangChain and Strands lab

Learn the building blocks of two agent frameworks by running small versions of them on a real language model in your browser. Chains, structured output, tools, agent loops, memory and multi-agent delegation, each with the real Python shown next to it.

Honest label: LangChain and Strands are Python libraries (LangChain also has a JavaScript version), and neither runs inside this page. This lab rebuilds the same ideas in a few lines of JavaScript on a small open model running locally through WebLLM and WebGPU, and shows the real Python beside each exercise. Small models make mistakes, which is part of the lesson. Library APIs change, so check the LangChain and Strands documentation before relying on any detail.
