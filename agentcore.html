AgentCore concepts (a real agent loop, local tools)

AgentCore lab

Run a small agent that picks tools, one step at a time. Around it sit the pieces AgentCore provides as managed services: a runtime for the loop, a gateway of tools, memory, identity with scopes, policy rules, and observability traces. Switch the planner between scripted rules and a real language model.

Honest label: the agent loop, tools, scopes, policy checks, approval step and traces are real code running in your browser against made-up data. AgentCore is an AWS service and nothing here calls it. The policy rules imitate a Cedar-style policy, and the model planner uses a small on-device model through WebLLM, so expect it to be less reliable than a production model. That unreliability is useful: it shows why guardrails matter.
