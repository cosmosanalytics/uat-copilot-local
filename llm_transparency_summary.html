🧠 LLMs Are Transparent

Mechanistic Interpretability · Sparse Autoencoders · Circuit Analysis
September 2026
LLMs are the first AI systems we can genuinely open up and read — every weight, activation, and attention pattern is a number you can inspect. Unlike the human brain, there is no "black box" in principle — only in practice.
What "Transparent" Means
🔬
Attention heads are specialized. Specific heads do induction, name-binding, and syntax copying — identifiable, nameable, surgically removable.
🗂️
SAEs decompose representations. Sparse Autoencoders extract thousands of human-readable features ("French city", "code variable", "uncertainty hedge") linked to specific neurons.
⚗️
Lesioning works as predicted. Ablate induction heads → working memory collapses. Ablate epistemic gating → confident hallucinations emerge.
🌐
Neuronpedia / Neuroscope make this browsable — any neuron in GPT-2 or Gemma shows exactly which tokens activate it, with real examples and auto-interpreted descriptions.
Functional Brain Mapping (Metaphor)
L0–5 · Sensory / Token Encoding L6–12 · Induction / Syntax Heads L13–20 · Semantic Association L21–26 · Epistemic Gating L27–31 · Output / Motor Decoding
The mapping holds functionally, not anatomically. LLMs develop regional specialization the same way brains do — not by design, but because it is computationally efficient. The residual stream acts as a readable shared scratchpad between layers.

Three Circuits — Real Research Basis
🌍
Analogical Reasoning — mid-layer semantic heads bind entity–relation pairs. Slower, world-knowledge-dependent.
💻
Induction (Code Circuit) — early heads (L1–3) match prior token patterns. Fast, purely syntactic, Neel Nanda 2022.
🛡️
Epistemic Guardrail — late attention heads calibrate uncertainty and hedging. Ablation → sycophancy / hallucination. Anthropic 2023.
No prior AI system offered concept-level internal readability. The transformer's residual stream is a readable scratchpad — mechanistic interpretability is learning to read it.
