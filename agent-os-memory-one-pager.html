1 The Computing Metaphor: Brain vs. Kernel vs. Storage
The CPU / ALU

🧠 LLM Brain

Pure Reasoning & Stateless: Brilliant at token reasoning, logic synthesis, and planning—but suffers from instant amnesia once a turn ends. Holds no memory on its own.

Equivalent: Arithmetic Logic Unit (ALU)
The Kernel / Arbiter

⚙️ Agent Core OS

The Runtime Orchestrator: Manages lifecycle (Listen → Retrieve → Prompt → Reason → Guard → Act). Dispatches tool calls, enforces safety boundaries, and manages dynamic context assembly.

Equivalent: Linux Kernel & Syscall Manager
The Storage Hierarchy

📚 Memory Documents

External Persistent Vaults: Where rules, facts, entity links, and multi-agent states live. The Agent Core reads these to assemble the prompt and writes back newly acquired state updates.

Equivalent: RAM, SSD, Disk & IPC Bus

3 The 4 Memory Documents: Where Knowledge Lives & Evolves
📋 Procedural Memory
Analogy: The SOP Playbook on Disk
What it keeps: SKILL.md runbooks defining step sequences, input schemas, and fallback tactics.
⚡ Core Action: Paged into working RAM only when intent triggers checkout.
🔍 Semantic Memory
Analogy: Indexed Encyclopedia
What it keeps: Embedding vectors over student handbooks, bylaws, and robotics lab safety rules.
⚡ Core Action: Cosine similarity search pulls only relevant paragraph (§4.2).
🕸️ Relational Memory
Analogy: Live Entity Registry
What it keeps: Graph triples linking Tim → Grade 7, Mr. Davis → Advisor, Kit #4 → Locker B-12.
⚡ Core Action: Deterministic traversal with strict zero-hallucination queries.
📡 Shared State (IPC)
Analogy: Staff Room Blackboard
What it keeps: Live custody tokens, active locks, waiver tickets, and pending peer approvals.
⚡ Core Action: Coordinates multi-agent handoffs between Robot, Teacher, & Lockers.
4 The Two-Way Connection: Read (Page-In) & Write (Page-Out) Cycles

📖 The Read Cycle: Dynamic Context Assembly (Page-In)

  • 1. DETECT Intent Parsing: Student requests Kit #4. Core detects checkout request and calls skill loader.
  • 2. FETCH Multi-Store Retrieval: Loads `borrow_kit.md`, queries Graph for Tim's grade (7), and fetches Policy §4.2 via Vector RAG.
  • 3. BIND Context Window Binder: Synthesizes retrieved excerpts into an immutable prompt bundle for the LLM.
  • 4. REASON LLM Decision: LLM evaluates facts: Tim is Grade 7, requires Grade 9 or waiver → Request waiver.

✍️ The Write Cycle: Memory Consolidation (Page-Out)

  • 1. GUARD Interception & Validation: Core verifies physical action; blocks unauthorized locker door opening.
  • 2. DISPATCH A2A Messaging: Posts pending waiver ticket to Shared Blackboard; pings Mr. Davis's Teacher Agent.
  • 3. MUTATE Graph Consolidation: Once Mr. Davis approves, Core adds edge `(Tim)-[HAS_WAIVER]->(Kit#4)` to Graph DB.
  • 4. LOG Episodic Audit: Records time-stamped transaction trail into immutable compliance store.
