Amazon Bedrock Converse API shape (a real model on your device)

Bedrock lab

Send messages to a real language model running in your browser, using the request and response shapes of Bedrock's Converse API. Change the system prompt and inference settings, read the token usage, try a guardrail, and run a prompt A/B test on 12 labelled store messages.

Honest label: the model is a small open model running locally through WebLLM and WebGPU, not a model hosted on Bedrock, and nothing calls AWS. The request and response JSON follow the Converse API shape, and the boto3 snippet is what you would run against the real service. The guardrail here is a keyword filter standing in for Bedrock Guardrails, which are far more capable.
