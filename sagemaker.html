SageMaker job lifecycle (real scikit-learn, simulated service)

SageMaker lab

Walk the SageMaker lifecycle with real training: prepare data, run a training job with a live validation log, run a hyperparameter tuning job, deploy an endpoint, send it requests, and delete it.

Honest label: the training, tuning and predictions are real (scikit-learn in your browser). The service layer is imitated: job names, statuses and the endpoint are created by this page, not by AWS. Real jobs run on managed instances, write artifacts to S3 and bill while instances run.
