Financial World Model

10 tool calls — one per stage of a single applicant's standard life insurance / annuity journey (Application → Health Questionnaire → Records Check → Medical Exam → Biometric Trend Forecast → Underwriter Review → Rating & Premium Pricing → Policy Issuance → Premium Servicing / Accumulation → then either Claims Processing or Annuitization, depending on the product family). Each tool is a pure, deterministic function modeling the real math and gating rules of that stage (a debit-based risk-classification engine, a least-squares biometric-trend forecast, age/risk-adjusted premium pricing, contestability-period claim investigation, surrender-charge schedules). The decision of which stage to run is always just a pick from a short, fixed menu — so instead of a large tool-calling-specialized model, you can either pick the action yourself from a plain menu, or route a free-text request to it with a small (<2B parameter) local instruct model reading plain text — no native tool-calling API, no large model. Run stages manually to study the logic either way. The stage sequence and product lines are modeled loosely on a typical life insurance and annuity carrier's core business (see footer), simplified into a single illustrative pipeline — not a representation of any specific insurer's actual underwriting manual, rate tables, or contract terms.

Applicant
Product & application
A medical exam is triggered automatically if the life face amount is ≥ $500,000 or any medical condition is disclosed (a simplified version of real exam-requirement rules). Annuities skip medical underwriting risk-pricing in practice, but this pipeline still runs them through the same review stages for illustration — the risk tier just won't affect an annuity's premium math the way it does for life.
Accumulation
Outcome — Claims (life) or Annuitization (annuity)
Claims within the 2-year contestability window are denied if an undisclosed item was found during Records Check (material misrepresentation) — a simplified version of real contestability-clause investigations. Annuity surrender charges follow a declining 10-year schedule (9% in year 1 down to 0% by year 10+).

Run the case

Pick an action from the menu and click Execute — this calls the exact same stage functions shown above, directly, with no model deciding anything. It's the same job an LLM tool-calling orchestrator would do (choosing which tool to call next), just done by you from a plain menu instead of by typing a request to a model. The menu's stage-10 option automatically matches whichever product family is currently selected above — the other branch (Claims Processing vs. Annuitization) isn't offered.
Type what you want in plain English. A small local instruct model (no native tool-calling API — just plain text in, plain text out) reads your request plus the list of valid menu actions, and replies with which one to run. That reply is matched against the same fixed menu shown above and executed the same way — the model never computes any number itself, it only decides which of the fixed actions you meant. Just like the menu, it only ever offers the stage-10 branch matching whichever product family is currently selected above. Runs fully client-side via WebGPU.
