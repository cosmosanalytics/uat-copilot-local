Harness Coach & Helmet Engineered orchestration framework (LangGraph, AgentCore). Intercepts request, loads skill, runs retrieval, enforces guardrails.

Vector DB Magic Filing Cabinet LLM chunks text, adds contextual tags, generates embeddings. Finds semantic policy match: "Requires Grade 8+".
Knowledge Graph Web of Connected Facts LLM extracts entity triples (Tim)-[:IS_IN]->(Grade 7). Traverses lines to find Tim's grade and advisor (Mr. Davis).
MCP Server Universal USB Port LLM writes Python/TS tool code from REST API documentation. Executes SmartLocker.status("Kit-4") live via JSON-RPC.
LLM Brain Student at Open-Book Desk Pre-trained on trillions of tokens (next-word prediction). Synthesizes all facts into polite, grounded answer with zero guesswork.
