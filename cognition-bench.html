Does a team think better? A benchmark

The same on-device model works through the same refund cases in five ways. The cases are generated by code, so the right answer is known. The page counts correct answers, wrong answers sent, and escalations, with confidence intervals, so you can see whether more working memories improve thinking, or just add cost.

  1. One pass: One agent, one working memory, one answer. The baseline.
  2. Thinks harder: The same agent reasons step by step, then checks its own work in the same working memory.
  3. Three clones: Three separate working memories with identical contents, then a majority vote.
  4. One agent with a calculator: One working memory, but a tool does the date and money arithmetic.
  5. The team: An extractor, a calculator, a judge that sees only the computed facts, and a separate checker with a fresh working memory (and its own calculator). Disagreement is escalated to a person.

Honest label: the refund policy and cases are made up and generated by code, with answers computed by code. Results depend on the model you load and on the sample, and small samples are noisy, so a gap smaller than the confidence interval means nothing. This benchmark tests one kind of task, applying written rules to facts with some arithmetic. It does not show that teams are better in general. The conditions use different numbers of model calls, which the page reports as cost. Nothing leaves your device.
