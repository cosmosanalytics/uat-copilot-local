iWhat this is

A step-by-step copilot for automating two things in Visokio Omniscope entirely from chat: building a data workflow with Ask the Workflow Ninja, and building a dashboard with Report Ninja — no manual block-wiring or chart-dragging, all done by typing instructions into their chat panels. You paste your own sample data and functional spec below, this page turns it into ready-to-paste chat messages, then at each step a small vision-language model (SmolVLM) looks at a screenshot of your actual screen and tells you whether that step looks done. It only advises; you decide when to move on. Nothing is uploaded — the model and the screenshot both stay in this browser tab.

!The one rule that matters

Everything you do to Omniscope goes through the chat box in the Workflow Ninja or Report Ninja panel — never click, drag, or configure anything on the canvas or report yourself. If a block needs fixing, tell the Ninja in chat what's wrong; it can read its own output and correct itself. This keeps the whole process reproducible from a transcript instead of a recording of mouse movements.

2Your data and functional spec

Paste your own sample tables and build spec here. Workflow Ninja will not invent data on its own — if you skip this, it spends a minute searching your whole account for something matching, then stops and asks you for exact column names. Giving it real data up front is what makes the rest of this run fast and reliable.

Runs fully client-side: a SmolVLM model via Transformers.js on WebGPU, loaded through vision-worker.js (must be deployed alongside this file). Progress through this run is kept only in this browser tab's memory — reload the page and it resets. Nothing about your screen or anything you type into Omniscope is sent anywhere; the only network calls are the one-time model weight download (cached after first load) and whatever Omniscope itself does in its own tab.
