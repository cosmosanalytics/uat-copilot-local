Eight made-up countries, each led by an agent (a real on-device model)

A world run by agents

Each country in this made-up world is led by an agent that picks one priority a year. The world turns everyone's choices into growth, emissions, trade, climate damage and stability. Use the triggers to provoke six emergent behaviors, and an emergence watch tells you when each one shows up.

  1. Country agents: Eight made-up countries, each led by an agent with its own personality. Every year it picks one of five priorities.
  2. The world: Plain code. It combines the choices into growth, trade, emissions, temperature and stability, and adds a random event each year.
  3. Triggers: Experiments that provoke an emergent behavior: a growth boom, a seeded herd, a tariff shock, an aid appeal, trade clubs and a cascade of shocks.
  4. Emergence watch: Plain-code detectors that say whether the commons, herding, a trade spiral, free-riding, blocs and cascades are happening.
  5. You: Run the years, arm triggers, or take over one country.

Honest label: the countries, their numbers and the world model are made up and deliberately simple, so they say nothing about any real country. The language model only picks one letter a year for each country and, if you leave it on, writes a short news summary. The economy, trade, emissions, climate and events are plain code with assumptions I chose. The triggers change the world's rules or the news the agents see, and forced choices are marked. The emergence watch uses simple thresholds I chose, so treat its verdicts as hints. You can also run the agents as scripted rules, which needs no model. Small models make mistakes, and a country that gets no valid letter falls back to its default policy and is flagged. Nothing leaves your device.
