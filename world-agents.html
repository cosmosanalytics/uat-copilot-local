Eight made-up countries, each led by an agent (a real on-device model)

A world run by agents

Each country in this made-up world is led by an agent that picks one priority a year. The world turns everyone's choices into growth, emissions, trade, climate damage and stability. Watch what happens when each country does what is best for itself.

  1. Country agents: Eight made-up countries, each led by an agent with its own personality. Every year it picks one of five priorities.
  2. The world: Plain code. It combines the choices into growth, trade, emissions, temperature and stability, and adds a random event each year.
  3. You: Run the years, set the next event, or take over one country and play against the agents.

Honest label: the countries, their numbers and the world model are made up and deliberately simple, so they say nothing about any real country. The language model only picks one letter a year for each country and, if you leave it on, writes a short news summary. The economy, trade, emissions, climate and events are plain code with assumptions I chose. Small models make mistakes, and a country that gets no valid letter falls back to its default policy and is flagged. Nothing leaves your device.
